# Catalog source review

## Dailies original math

Statements and worked solutions were authored for this project. No contest statements are reproduced. Families: linear equations, Pythagorean triples, sampling without replacement, remainders, combinations, arithmetic sequences, algebraic identities, a modular cycle, and parity proof. Numeric keys follow their displayed derivations. The tests also verify exact number comparison; they do not establish contest difficulty calibration.

## Waterloo CCC / DMOJ

Catalog references use stable DMOJ problem codes and the canonical identity `waterloo:ccc:YEAR:J#`. Native problem labels are preserved. Automated fetches of DMOJ problem pages were blocked, so source statements remain external. Publicly indexed DMOJ lists provided identity checks:

- https://dmoj.ca/problems/?category=4&order=type&page=5&search=&show_types=1
- https://dmoj.ca/problems/?category=4&order=group&page=6&search=&show_types=1
- https://dmoj.ca/problems/?category=4&page=4&search=&show_types=1
- https://dmoj.ca/problems/?category=4&page=2&search=&show_types=1

Primary Waterloo archive: https://cemc.uwaterloo.ca/resources/past-contests

## Codeforces

Metadata staging uses https://codeforces.com/api/problemset.problems, documented at https://codeforces.com/apiHelp and https://codeforces.com/apiHelp/methods. It does not download statements, submit code, or activate unreviewed records. Network access occurs only when the explicit CLI command runs.

## Future sources

USACO (https://usaco.org/), USACO Guide (https://usaco.guide/problems), Waterloo math, additional DMOJ sources, and specific textbooks need source-specific review before statement ingestion. Availability online is not treated as permission to republish. The JSON import contract is available now for reviewed entries.
